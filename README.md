🍽️ Python Restoran Sipariş Sistemi

Bu proje, Python kullanılarak geliştirilmiş basit bir terminal tabanlı restoran sipariş uygulamasıdır.
Kullanıcı menüyü görüntüleyebilir, sepete ürün ekleyebilir ve toplam tutarı hesaplayabilir.

🚀 Özellikler
Menü görüntüleme
Sepete ürün ekleme
Sepetteki ürünleri listeleme
Toplam fiyat hesaplama
Basit terminal arayüzü
